## 1. Архитектура рабочего пространства и дизайн-система

Интерфейс **NeonRoute** построен на базе библиотеки **PyQt6** с использованием фирменной киберпанк-стилистики **Glassmorphism (палитра глубокого темного обсидиана `#0A0D14` с неоновыми акцентами Cyan `#00F0FF`, Sky Blue `#38BDF8`, Amber `#F59E0B`, Neon Pink/Magenta `#FF007F` и Neon Lime `#00FF66`)**.

Рабочая область декомпозирована на пять ключевых функциональных зон:

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ 1. ВЕРХНИЙ МЕНЮ-БАР (QMenuBar): Диалоги | Оформление | Система | Справка              │
├──────────────────────────┬─────────────────────────────────────────────────────────────┤
│ 2. ЛЕВАЯ БОКОВАЯ ПАНЕЛЬ  │ 3. ШАПКА АКТИВНОГО ЧАТА (ChatHeaderWidget)                  │
│    (SidebarWidget)       ├─────────────────────────────────────────────────────────────┤
│ • Бренд и логотип        │ 4. ЛЕНТА СООБЩЕНИЙ И СКРОЛЛИНГ (ChatStreamWidget)           │
│ • Карточка компаньона    │    • Баблы сообщений (ChatMessageWidget / RP / Assistant)   │
│   (только в РП-режиме)   │    • Спойлеры мыслей <thought>, HUD статуса, карточки      │

## 2. Верхний Меню-Бар (QMenuBar)

Верхнее меню (`ui/builders/menu_builder.py`) обеспечивает сквозной доступ ко всем системным диалогам, параметрам персистентности, профилям генерации и инструментам обслуживания:

### 2.1. Меню «💬 Диалоги»
| Пункт меню | Горячая клавиша | Обработчик в коде | Назначение и поведение |
| :--- | :---: | :--- | :--- |
| **📄 Новый диалог** | `Ctrl + N` | `_on_new_chat_clicked()` | Создает новый чистый диалог в текущем активном режиме. |
| **🎛️ Настройка текстовой модели (по умолчанию)...** | — | `_open_global_model_sampling_dialog()` | Открывает диалог `ModelSamplingDialog` в режиме `is_global_defaults=True`. Сохраняет базовые значения температуры, Min-P, Repetition Penalty и Max Tokens в `config.json`, которые будут автоматически наследоваться всеми новыми чатами. |
| **🖼️ Медиа галерея** | — | `_open_chat_media_gallery()` | Открывает модальное окно `ChatMediaGalleryDialog` со сводной сеткой миниатюр всех сгенерированных изображений из папки `outputs/` и сессионных подпапок. |
| **📂 Папка истории сессий** | — | Системный вызов | Открывает каталог `history/` в Windows Explorer, где хранятся файлы состояния диалогов `chat_<id>.json` и файлы хроники мира `cast_<id>.json`. |
| **🎨 Режим генерации иллюстраций** | — | Вложенное подменю | Переключает глобальный режим рендера арта: <br>• *Вручную (кнопка в сообщении)* — генерация запускается строго по клику на интерактивный чип под репликой.<br>• *Автоматически (сразу через Forge)* — рендер в Forge стартует сразу при получении тега от модели. |
| **📥 Экспорт текущей истории...** | — | `_on_action_export_clicked()` | Экспортирует текущую сессию в чистый структурированный JSON в папку `exports/` и подсвечивает созданный файл в Проводнике. |

## 3. Левая боковая панель (SidebarWidget)

Боковая панель (`ui/components/sidebar_widget.py`) имеет ширину от 260 до 320 px и отвечает за навигацию между чатами, контроль загрузки моделей и переключение сюжетных модулей:

```
┌────────────────────────────────────────────────────────┐
│ ⚡ NEON ROUTE (8GB VRAM Orchestrator)                   │
├────────────────────────────────────────────────────────┤
│ [Блок карточки персонажа] (виден только в РП режиме)   │
│ • 🎭 Имя персонажа                                     │
│ • [ 📜 Правила мира и Лор ↗ ]                          │
│ • [ 🎴 Выбор компаньона ]                              │
├────────────────────────────────────────────────────────┤
│ МОДЕЛЬ LM STUDIO:                                      │
│ [ QComboBox: Выбор модели                  ] [ 🔄 ]    │
├────────────────────────────────────────────────────────┤
│ ДИАЛОГИ                                  [ + Новый ]   │
│ ┌────────────────────────────────────────────────────┐ │
│ │ 👤 Дэниэл (Инженер)              🛠️ Инженер  [🗑️] │ │
│ │ 👤 Элейна                         🎭 Ролевой  [🗑️] │ │
│ │ 👤 Новый диалог                  ⚡ Ассистент [🗑️] │ │
│ └────────────────────────────────────────────────────┘ │
├────────────────────────────────────────────────────────┤
│ БЫСТРЫЕ ПАПКИ В ПРОВОДНИКЕ:                            │
│ [ 📁 workspace ]    [ 🎨 outputs ]    [ 🎙️ audio ]     │
└────────────────────────────────────────────────────────┘
```

### 3.1. Блок карточки персонажа (активен только в режиме Roleplay)
- **Имя компаньона**: отображает текущего активного персонажа или сообщение `Компаньон не выбран`.
- **Кнопка `[ 📜 Правила мира и Лор ↗ ]`**:
  - Открывает интерактивный Дашборд мастера `CampaignInfoDialog` (5 вкладок: Память и статус, Инвентарь, Лор и завязка, Второстепенные персонажи, Локация и атмосфера).
  - Если карточка не загружена, кнопка блокируется со статусом `📜 Модуль не загружен`.
- **Кнопка `[ 🎴 Выбор компаньона ]`**:
  - Открывает галерею персонажей `CharactersGalleryDialog`.
  - После первого хода игрока кнопка блокируется со статусом `🔒 Компаньон зафиксирован` во избежание повреждения сюжетной линии.

### 3.2. Селектор модели LM Studio
- **Выпадающий список `lm_combo`**: отображает обнаруженные в LM Studio модели. Выбор модели немедленно инициирует фоновую загрузку в память через CLI `lms load` с оптимизированным контекстом режима.
- **Кнопка `[ 🔄 ]`**: запускает фоновый рабочий поток `ModelDiscoveryWorker` для немедленного пересканирования доступных моделей в каталоге LM Studio.
- **Индикатор фиксации**: при отправке первого сообщения в сессии выбор блокируется, фиксируя модель за данным чатом.

### 3.3. Кнопка «+ Новый» (Диалог создания чата)
Клик по кнопке открывает всплывающий виджет `NewChatDialog` с выбором одного из 3 целевых режимов:
- **🎭 РП Чат**: создает ролевую сессию с активным компаньоном, инициализирует файлы `history/chat_<id>.json` и `history/cast_<id>.json`;
- **💬 Ассистент**: создает диалог с Эларией, подключает долговременную память LanceDB и быстрые арт-чипы;
- **🛠️ Инженер**: создает сессию в песочнице с изолированной директорией `workspace/projects/<id>/`.

### 3.4. Список диалогов (`chat_list_widget`)
- **Клик ЛКМ**: бесшовное переключение на выбранный диалог с мгновенной отрисовкой сообщений из `history/chat_<id>.json`.
- **Индикация аватара**: круглый аватар 30x30 px, отображающий аватар персонажа (в РП) или персональный аватар сессии ассистента.
- **Бейджи режимов**:
  - `🛠️ Инженер` (янтарный цвет `#F59E0B`);
  - `🎭 Ролевой чат` (фиолетовый цвет `#C084FC`);
  - `⚡ Ассистент` (неоновый циан `#00F0FF`).
- **Кнопка удаления `[ 🗑️ ]`**: удаляет сессию из истории и зачищает связанные медиафайлы.
- **Контекстное меню ПКМ по элементу диалога**:
  - `✏️ Переименовать` — изменение заголовка сессии;
  - `👤 Персонаж игрока` (для РП) — выбор активного героя/протагониста для данной сюжетной линии;
  - `🗑️ Удалить диалог` — удаление с подтверждением.

### 3.5. Кнопки быстрого открытия папок в Проводнике Windows
- `[ 📁 ]` — открывает рабочую директорию песочницы (`WORKSPACE_DIR`);
- `[ 🎨 ]` — открывает папку сгенерированных артов (`OUTPUTS_DIR`);
- `[ 🎙️ ]` — открывает папку синтезированных аудиозаписей (`AUDIO_DIR`).

## 4. Шапка активного чата (ChatHeaderWidget)

Шапка чата (`ui/components/chat_header_widget.py`) размещена над лентой сообщений и обеспечивает оперативное управление сессией:

```
┌────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ (Avatar 48x48)  Элария (или Имя персонажа)           [ 🖼️ Фон сцены ]  [ QComboBox: Модель Forge ]  [📥] [🎙️] [⛶] │
│                 В сети • Вы: Игрок (или статус задачи)                                                     │
└────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

1. **Круглый интерактивный аватар (48x48 px)**:
   - **Клик ЛКМ**: открывает полноэкранный просмотрщик `AvatarLightboxDialog` с затемнением фона.
   - **Клик ПКМ**: открывает контекстное меню аватара (`_show_avatar_menu`).
2. **Контекстное меню аватара**:
   - `🖼️ Изменить аватар...` — запуск `AvatarCropDialog` (интерактивный зум и панорамирование 300px круга с экспортом в 512x512 PNG);
   - `⚙️ Настройки модели...` — запуск `ModelSamplingDialog` для текущего чата (индивидуальный оверрайд сэмплинга);
   - `🔍 Поиск по сообщениям` — вызов поисковой строки `SearchBarWidget` (`Ctrl + F`);
   - `🖼️ Медиа галерея` — сводка артов текущей сессии `ChatMediaGalleryDialog`;
   - `📂 Файлы чата в проводнике` — открытие сессионной папки `outputs/sessions/<id>/` или `workspace/`;
   - `❌ Сбросить аватар` — возврат к каноничному аватару карточки или ассистента;
   - `✏️ Переименовать...` (в РП) — смена имени персонажа/диалога.
3. **Имя и динамический статус (`HeaderStateController`)**:
   - Отображает имя собеседника и текущую роль;
   - В РП-режиме отображает активного героя игрока: `🎭 Элейна • Вы: Дэниэл`;
   - Во время инференса SD Forge транслирует живой прогресс и текущий этап: `✋ Улучшение рук: 45%`, `👁️ Детализация взгляда...`, `🔍 Повышение четкости: 80%`.
4. **Кнопка `🖼️ Фон сцены` (видна только в режиме Roleplay)**:
   - Меню быстрого управления фоном диалога:
     - `📁 Выбрать изображение...` — выбор локального файла картинки;
     - `🎨 Сгенерировать фон (Forge)` — автоматический запуск генерации пейзажа без людей (`scenery, empty environment, no humans`);
     - `❌ Сбросить фон` — удаление фона сцены.
5. **Селектор модели генерации `forge_combo`**:
   - Выпадающий список моделей SD WebUI Forge: `✨ Арт-директор (Авто)`, 4 базовых чекпоинта («Золотая четверка») и все обнаруженные на диске `.safetensors`.
   - Позволяет зафиксировать конкретную модель для артов в этом чате или оставить автоматический роутинг Арт-директора.
6. **Кнопки быстрых действий**:
   - `[ 📥 ]` — экспорт истории чата в JSON;
   - `[ 🎙️ ]` — озвучка последнего сообщения через F5-TTS;
   - `[ ⛶ ]` — полноэкранный режим (`F11`).

### 5.1. Левая панель: Таблица зарегистрированных моделей
- **Колонка «Вкл»**: чекбокс активности модели. Только активные модели участвуют в автоматическом роутинге Арт-директора.
- **Колонка «Название модели»**: пользовательское отображаемое имя.
- **Колонка «Чекпоинт Forge»**: имя файла `.safetensors`, установленного в каталоге Forge.
- **Колонка удаления `[ 🗑️ ]`**: удаление модели из реестра.
- **Кнопка `[ 🔄 Сканировать Forge ]`**:
  - Запускает фоновый поток `ForgeScanWorker`, опрашивающий API Forge (`/sdapi/v1/sd-models`) и файловую систему `C:\neyroGPD\webui\models\Stable-diffusion`.
  - Автоматически находит новые скачанные чекпоинты и регистрирует их в таблице с автогенерацией безопасных дефолтных настроек.
- **Кнопка `[ 🌐 Каталог Civitai ]`**:
  - Открывает встроенный браузер каталога Civitai (`CivitaiCatalogDialog`).

### 5.2. Правая панель: Редактор параметров модели
1. **Основные метаданные**:
   - `Название`: имя профиля.
   - `Чекпоинт`: выпадающий список доступных чекпоинтов Forge с поддержкой ручного ввода.
   - `Кнопка 🌐 Автонастройка параметров (Civitai)`:
     - Вычисляет хеш AutoV2 SHA-256 файла модели на диске.
     - Выполняет запрос к API Civitai (`CivitaiParamsWorker`) с таймаутом 4.0 сек.
     - Автоматически считывает и выставляет рекомендованный автором сэмплер, количество шагов, CFG Scale, Clip Skip, апскейлер Hires.fix и силу денойза.
     - При отсутствии интернета или отсутствии модели в базе Civitai безопасно применяет проверенные Safe Defaults.
   - `Чекбокс Использовать по умолчанию`: назначает модель для всех нейтральных запросов, где не указан конкретный стиль (например, «нарисуй девушку в парке»). В системе может быть только одна модель по умолчанию.
   - `Триггеры стиля (через запятую)`: список ключевых слов (например: `киберпанк, неон, sci-fi, android`). При наличии хотя бы одного триггера в запросе роутер мгновенно выбирает эту модель по правилу (score = 0.95), исключая ошибки нейросети.
2. **Параметры рендера (Pipeline)**:
   - `Семплер`: DPM++ 2M Karras, Euler a, DPM++ SDE Karras, Euler, DDIM.
   - `Шаги (Steps)`: от 10 до 60 (рекомендуется 20–28).
   - `CFG Scale`: от 1.0 до 15.0 (рекомендуется 5.0–7.0).
   - `Clip Skip`: 1 для фотореализма, 2 для аниме и мерджей.
   - `Hires.fix апскейлер`: 4x-UltraSharp (фотореализм), R-ESRGAN 4x+ Anime6B (аниме), DAT x2, Lanczos, Latent.
   - `Денойз Hires`: от 0.10 до 0.70 (эталон 0.32–0.35 для ESRGAN).
   - `Негативный промпт`: канонический негативный промпт для чекпоинта с автоподстановкой под тип модели (`_get_default_negative`).
3. **Семантический роутинг (FastEmbed CPU ONNX)**:
   - `Описание эстетики для FastEmbed` (`routing_description`): плотное смысловое описание стилистики, объектов, жанра, освещения и ракурсов. Используется для построения векторных эмбеддингов и семантического сопоставления без затрат VRAM.
   - `Подсказка для Эларии` (`llm_guidance`): инструкция для текстовой модели при составлении промпта (максимум 160 символов, до 8 тегов).

### 5.3. Нижняя панель: Тестирование роутинга в реальном времени
- Поле ввода тестового запроса и кнопка `[ 🎯 Проверить выбор ]`.
- Неблокирующий расчет косинусного сходства через фоновый `RoutingTestWorker` на CPU:
  - Выводит выбранную модель, чекпоинт и причину выбора:
    - 🟢 `(совпадение по триггеру стиля)` — мгновенный переход по прямому совпадению ключевого слова;
    - 🔵 `(семантическое сходство FastEmbed: 0.88)` — победа по косинусному расстоянию векторов;
    - 🔷 `(по умолчанию для нейтральных запросов)` — выбор дефолтной модели;
    - ⚪ `(фоллбэк)` — аварийный выбор.
- **Кнопка `[ 💾 Сохранить ]`**:
  - Атомарно сохраняет все модели в `data/art_director_models.json`;
  - Обновляет кэш эмбеддингов FastEmbed в памяти;
  - Синхронизирует внутренний реестр моделей `MODEL_REGISTRY`.

### 5.4. Сопутствующие диалоги Civitai

## 10. Тонкая настройка сэмплинга модели (`ModelSamplingDialog`)

Диалог вызывается через меню **«💬 Диалоги» $\rightarrow$ «🎛️ Настройка текстовой модели (по умолчанию)...»** (для глобальных дефолтов в `config.json`) или через контекстное меню аватара в шапке **«⚙️ Настройки модели...»** (для индивидуального оверрайда текущей сессии):

```
┌────────────────────────────────────────────────────────┐
│ ⚙️ Параметры сэмплинга (🎭 Ролевой чат)                 │
├────────────────────────────────────────────────────────┤
│ Температура (Temperature):                     [ 1.10 ]│
│ ───●────────────────────────────────────────────────── │
│ Min-P Sampling:                                [ 0.05 ]│
│ ─────●──────────────────────────────────────────────── │
│ Штраф за повторы (Repetition Penalty):         [ 1.02 ]│
│ ─●──────────────────────────────────────────────────── │
│ Макс. токенов (Max Tokens):                    [ 4096 ]│
│ ──────────────────────────────────────●─────────────── │
│ [x] 🎲 Режим Гейммастера (DM / Ведущий игры)           │
├────────────────────────────────────────────────────────┤
│ [ 🔄 Сбросить по умолчанию ]     [ Отмена ] [ 💾 Сохранить ] │
└────────────────────────────────────────────────────────┘
```

- **Температура (Temperature)**:
  - Диапазон: от 0.10 до 2.00 с шагом 0.05;
  - *Режим «Ассистент»*: дефолт `0.70` (баланс креативности и фактологии);
  - *Режим «Ролевой чат»*: дефолт `1.10` (богатый литературный язык без шаблонности);
  - *Режим «Инженер»*: аппаратно зафиксирована на `0.15` (детерминированный синтаксис кода и инструментов).
- **Min-P Sampling**:
  - Диапазон: от 0.00 до 0.20 (дефолт `0.05`). Отсекает маловероятные токены относительно вероятности топ-токена, предотвращая галлюцинации и мусорные символы.
- **Штраф за повторы (Repetition Penalty)**:
  - Диапазон: от 1.00 до 1.30 (дефолт `1.02` для РП, `1.05` для Ассистента, `1.00` для Инженера).
- **Макс. токенов (Max Tokens)**:
  - Диапазон: от 256 до 4096 токенов (привязан к аппаратному мастер-предохранителю `MASTER_MAX_RESPONSE_TOKENS = 4096`).
- **Чекбокс `🎲 Режим Гейммастера (DM)`** (в ролевом режиме):
  - Активирует архетип ведущего игры: объективный мир, броски проверок сложности `<check>`, генерация последствий без подыгрывания игроку.
- **Кнопка `[ 🔄 Сбросить по умолчанию ]`**:
  - Возвращает значения к эталонным профилям режима из `MODE_PROFILES`.

## 11. Нижняя строка статуса (`MainStatusBar`)

Строка статуса (`ui/components/status_bar_widget.py`) размещена в самом низу окна и служит центром аппаратной телеметрии:

```
[ VRAM: 4850 / 8192 MB (59.2%) • 58°C ]  [ RAM: 8.4 / 16.0 GB (52%) ]  [ ⚡ Старт LMS ]  ● LM Studio (1234)  [ ▶ Запустить Forge ]  ● Forge (7860)  ● F5-TTS (5010)
```

1. **Метрика VRAM (видеопамять GPU)**:
   - Опрашивает видеокарту через драйвер `pynvml` (NVML) каждые 2.8 секунды без создания сторонних процессов.
   - Цветовая индикация порога безопасности:
     - 🟢 **Зеленый (`#00FF66`)**: загрузка $< 5500$ МБ (безопасная зона);
     - 🟡 **Желтый (`#FFE600`)**: загрузка $5500 - 7199$ МБ (высокая нагрузка);
     - 🔴 **Розово-красный (`#FF007F`)**: загрузка $\ge 7200$ МБ (риск падения скорости и вылета в Shared VRAM).
   - Отображение температуры чипа GPU (`• 58°C`).
2. **Метрика RAM (оперативная память)**:
   - Замер физической оперативной памяти через `psutil`.
3. **Тумблер и статус LM Studio**:
   - Кнопка `⚡ Старт LMS` / `⚡ Стоп LMS`: фоновый запуск/остановка демона `lms server start` / `lms server stop`.
   - Неоновый светодиод `● LM Studio (1234)`: зеленый при активном REST API, красный при недоступности порта.
4. **Тумблер и статус SD WebUI Forge**:
   - Кнопка `▶ Запустить Forge` / `⏹ Остановить Forge`: запуск фонового процесса `forge_launcher.bat` в бесшумном режиме (`CREATE_NO_WINDOW`).
   - Неоновый светодиод `● Forge (7860)`: отслеживает готовность порта 7860.
5. **Индикатор F5-TTS**:
   - Светодиод `● F5-TTS (5010)`: отслеживает статус легковесного сервера синтеза речи на CPU.

## 13. Локальные напоминания и таймеры

В NeonRoute интегрирована детерминированная подсистема локальных напоминаний (`ReminderController`, `services/memory_db.py`):
1. **Формат естественных команд**:
   - «Элария, напомни мне проверить отчет через 15 минут»
   - «Напомни завтра в 14:30 созвон по проекту»
   - «Напомни сделать бэкап через 45 секунд»
2. **Перехват без вызова LLM**:
   - Конструкция парсится библиотекой `dateparser` и сохраняется в таблицу `reminders` базы `data/memory.db`.
   - В чат выводится подтверждение: `Договорились, напомню 24.10.2026 в 14:30: «созвон по проекту».`
3. **Тройное уведомление при срабатывании таймера**:

   - Системный Windows Tray Balloon со звуком;

## 15. Команды прямого рендера (`!art`)

Для прямого создания изображений без обращения к языковой модели поддерживаются команды прямого рендера (`!art`, `!арт`, `!img`, `!картинка`):

```bash
!art 1girl, cyberpunk samurai, neon city --model cyberrealistic --ar wide --steps 25 --cfg 6.0 --neg bad anatomy, blurry
```

### Поддерживаемые CLI-флаги директ-арта:
- `--model <id/ckpt>` — выбор модели/стиля (`realistic`, `cyberrealistic`, `artistic`, `anime`);
- `--ar <wide|portrait|square|16:9|9:16|1:1>` — пропорции кадра;
- `--steps <int>` — количество шагов сэмплинга (от 10 до 60);
- `--cfg <float>` — шкала соответствия промпту (CFG Scale);
- `--denoise <float>` — сила денойза Hires.fix;
- `--hires <on|off>` — включение/выключение апскейла Hires.fix;
- `--ad <on|off>` — принудительное включение/выключение ADetailer (детектора лиц YOLO);
- `--seed <int>` — фиксация сида генерации (Seed Lock);
- `--neg <текст>` или `negative: <текст>` — явный негативный промпт.
