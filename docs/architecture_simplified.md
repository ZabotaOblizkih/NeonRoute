# architecture_simplified.md
# Архитектура NeonRoute простым языком

> **Для кого этот документ**: Руководство написано простым языком «на пальцах». Оно предназначено для разработчиков, пользователей и энтузиастов, которые хотят быстро понять устройство программы **NeonRoute v0.8.0-beta**, не продираясь через сложный академический код.

---

## 1. Концепция приложения: Аналогия с киностудией и лабораторией

Представьте, что **NeonRoute** — это не просто окно с чатом, а **слаженная творческая киностудия и исследовательская лаборатория**, работающая на вашем компьютере:

```
                  ┌─────────────────────────────────────────┐
                  │          Главный Дирижёр (UI)           │
                  │              (main_window.py)           │
                  └────────────────────┬────────────────────┘
                                       │
                  ┌────────────────────┴────────────────────┐
                  │       Диспетчер режимов (Режиссёр)      │
                  │           (mode_coordinator.py)         │
                  └────────────────────┬────────────────────┘
                                       │
         ┌─────────────────────────────┼─────────────────────────────┐
         ▼                             ▼                             ▼
┌─────────────────┐           ┌─────────────────┐           ┌─────────────────┐
│ 💬  Ассистент   │           │  🎭 Ролевой чат │           │   ⚡ Инженер    │
│    (Элария)     │           │   (Tavern / RP) │           │   (Песочница)   │
└────────┬────────┘           └────────┬────────┘           └────────┬────────┘
         │                             │                             │
         └─────────────────────────────┼─────────────────────────────┘
                                       │
                                       ▼
                   ┌───────────────────────────────────────┐
                   │    Страж видеопамяти (VRAM Arbiter)   │
                   │           (vram_arbiter.py)           │
                   └───────────────────┬───────────────────┘
                                       │
                   ┌───────────────────┴───────────────────┐
                   │   Очередь задач (TaskQueueWorker)    │
                   │           (task_queue.py)             │
                   └───────────────────┬───────────────────┘
                                       │
        ┌──────────────────────────────┼──────────────────────────────┐
        ▼                              ▼                              ▼
┌───────────────┐              ┌───────────────┐              ┌───────────────┐
│ 🧠 Мозг (LLM) │              │ 🎨 Художник   │              │ 💾 Хранитель  │
│ (LM Studio)   │              │  (SD Forge)   │              │ (LanceDB/DB)  │
└───────────────┘              └───────────────┘              └───────────────┘
```

### Кто за что отвечает в этой команде:
1. **Главный Дирижёр (`MainWindow`)** — принимает ваши команды, следит за окнами, шрифтами, анимациями и киберпанк-стилем (стеклянные полупрозрачные панели Glassmorphism).
2. **Диспетчер режимов (`ModeCoordinator`)** — режиссёр за кулисами. Когда вы переключаетесь из диалога в ролевой чат, он убирает рабочий стол ассистента, изолирует память и открывает сцену с декорациями и сценарием карточки.
3. **Страж видеопамяти (`VRAMArbiter`)** — строгий охранник ресурсов вашей видеокарты (8 ГБ VRAM). Он следит за тем, чтобы умная текстовая нейросеть (LLM) и художник графики (SD Forge) никогда не дрались за видеопамять одновременно. Если надо нарисовать сцену — он вежливо попросит текст уйти в оперативку, освобождая место для холста и кистей.
4. **Единая очередь (`TaskQueueWorker`)** — метрдотель, который выдает видеокарте ровно по одной тяжелой задаче за раз (`max_workers = 1`). Компьютер никогда не зависает и не вылетает с ошибкой памяти.
5. **Мозговой центр (`LM Studio`)** — локальный мыслитель. Сочиняет реплики, анализирует файлы, формулирует промпты для художника и пишет код.
6. **Художник (`SD WebUI Forge`)** — рисует портреты персонажей, пейзажи и кадры происходящего в высоком разрешении.
7. **Инженер в защитном костюме (`SubagentEngineer` + `ToolEngine`)** — сидит в изолированной песочнице `workspace/`. Сам пишет Python-скрипты, запускает их, проверяет результаты и создает готовые файлы Excel и Word.
8. **Хранитель памяти (`MemoryDB` + `LanceDB`)** — библиотекарь, который на процессоре (не тратя ни мегабайта видеопамяти) мгновенно находит важные факты о вас или события прошлых глав истории.

## 2. Путь сообщения: От нажатия клавиши Enter до ответа

### Сценарий 1: Обычный диалог («Привет, расскажи про квантовые компьютеры»)
1. **Отправка**: Вы нажимаете Enter. Поле ввода превращается в кнопку остановки «⏹».
2. **Анализ**: `MainWindow` определяет, что это текстовый вопрос, и создает задачу с высоким приоритетом (`PRIORITY_HIGH`).
3. **Подтягивание памяти**: Хранитель памяти на процессоре за считанные миллисекунды проверяет базу LanceDB и подклеивает в системный контекст пару фактов (например, что вы программист и любите короткие ответы).
4. **Инференс**: Текстовый мозг в LM Studio начинает генерировать ответ.
5. **Стриминг**: Буквы передаются по кусочкам и с частотой ~28 кадров в секунду печатаются в бабле чата без малейших задержек интерфейса.
6. **Сохранение**: Реплика записывается в файл сессии `history/chat_<id>.json`.

### Сценарий 2: Запрос на иллюстрацию («Нарисуй киберпанк девушку с катаной»)
1. **Перехват триггера**: Программа видит команду `!art` или просьбу *«Нарисуй...»*.
2. **Арт-директор (`ModelRouter`)**: Векторный классификатор на процессоре за 3 миллисекунды решает, какой чекпоинт подходит лучше всего (например, *CyberRealistic Classic* для киберпанка).
3. **Освобождение видеопамяти**:
   - `VRAMArbiter` командует текстовой модели временно выгрузиться из видеопамяти.
   - Драйвер подтверждает: свободно более 3800 МБ VRAM.
4. **Рендеринг в Forge**:
   - 1-й проход: создается базовый набросок кадра.
   - 2-й проход (Hires.fix): векторный апскейлер делает изображение кристально четким.
   - Нейросеть YOLO (ADetailer) находит лицо и аккуратно прорисовывает ресницы, зрачки и черты лица.
5. **Очистка и возврат**:
   - Чекпоинт Forge сбрасывается в системную RAM.
   - Видеопамять свободна. Через 1.2 секунды текстовая модель тихо возвращается обратно на случай продолжения диалога.
6. **Показ результата**: Изображение появляется прямо в сообщении чата. По клику открывается полноразмерный просмотрщик.

### Сценарий 3: Создание таблицы Инженером («Сделай смету ремонта в Excel»)
1. **Определение задачи**: Система видит маркер документа (*«сделай смету в Excel»*).
2. **Фаза Архитектора**: Создается план задачи — формат `excel`, целевой файл `make_doc.py`.
3. **Git-чекпоинт**: Песочница фиксирует слепок файлов до начала работы.
4. **Написание кода**: Инженер генерирует чистый Python-скрипт с библиотекой `openpyxl`.
5. **Статическая проверка (CodeValidator)**: Линтер проверяет синтаксис ДО запуска, исправляя неправильные вызовы формул (например, заменяет русские формулы на нативные английские `=SUM(...)` через свойство `.value`).
6. **Запуск и проверка**: Скрипт выполняется в изолированной среде. Если возникла ошибка, система сама откатывает файлы через `git reset` и пробует другой вариант.
7. **Готовый артефакт**: В чате появляется интерактивная карточка с зеленой кнопкой «[ 📄 Открыть файл ]». Один клик — и Excel запущен на компьютере!

## 3. Как устроено безопасное выключение (Watchdog & Shutdown)

Многие локальные программы зависают при выходе, оставляя в диспетчере задач «зомби-процессы», которые продолжают греть видеокарту. В NeonRoute это исключено:

1. **Клик по крестику окна**: Главное окно немедленно исчезает с экрана, а вместо него появляется аккуратная карточка с надписью *«Завершение работы... Освобождение VRAM»*.
2. **Аварийный таймер (8 секунд)**: В фоновом режиме запускается независимый таймер безопасности. Если что-то пойдет не так, через 8 секунд программа гарантированно закроется сама.
3. **Первым делом — Forge**: Программа принудительно и рекурсивно завершает всё дерево процессов Forge через системную команду Windows `taskkill /F /T /PID`. Это мгновенно освобождает до 4 ГБ VRAM.
4. **Зачистка остатков**: Проверяются все процессы Python, чтобы ни один фоновый скрипт не остался висеть в памяти.
5. **Выгрузка LM Studio**: Отправляется команда на выгрузку моделей.
6. **Полная тишина**: Все потоки завершены, приложение закрыто.

## 4. Навигатор для разработчика: В какой файл смотреть?

Если вы хотите внести изменения или разобраться в определенной части:

| Если задача связана с... | Ищите в этих файлах | Что внутри |
| :--- | :--- | :--- |
| **Характером и ответами Эларии** | `services/assistant_prompt_builder.py`<br>`ui/controllers/assistant_flow_controller.py` | Личность Эларии, подача ответов, правила общения. |
| **Ролевой игрой и карточками персонажей** | `services/tavern_parser.py`<br>`services/roleplay_prompt_builder.py`<br>`services/rp_cast_manager.py` | Чтение карточек Tavern/Chub, 11 архетипов, отряд, инвентарь, квесты. |
| **Написанием кода и песочницей** | `services/subagent_engineer.py`<br>`services/code_engine.py`<br>`services/tool_engine.py` | Автономный инженер, AST-скелеты, патчер SEARCH/REPLACE, инструменты. |
| **Защитой и безопасностью файлов** | `services/sandbox_guard.py`<br>`services/sandbox_manager.py` | Аудит-хуки, запрет выхода за пределы workspace, изоляция папок. |
| **Выбором моделей для картинок** | `services/model_router.py`<br>`data/art_director_models.json` | Векторный выбор подходящей модели по смыслу текста через FastEmbed. |
| **Генерацией в Stable Diffusion** | `services/forge_client.py`<br>`services/forge_models.py`<br>`services/art_director/director.py` | Настройки шагов, сэмплеров, Hires.fix, лиц ADetailer, негативных промптов. |
| **Памятью и воспоминаниями** | `services/memory_db.py`<br>`services/memory_extractor.py` | Векторная база LanceDB, база SQLite, извлечение фактов о пользователе. |
| **Кнопками, цветами и стилем** | `ui/styles.py`<br>`ui/components/chat_bubble.py`<br>`ui/components/chat_input_panel.py` | Неоновые стили QSS, капсула ввода, Glassmorphism-баблы. |
| **Запуском процессов и выключением** | `services/process_manager.py`<br>`ui/workers/shutdown_worker.py` | Запуск LMS и Forge, безопасный выход с таймером на 8 секунд. |
| **Меню, клавишами и диалогами** | `ui/builders/menu_builder.py`<br>`ui/main_window.py` | Горячие клавиши (Ctrl+N, Ctrl+F, F11), вызовы модальных окон. |
